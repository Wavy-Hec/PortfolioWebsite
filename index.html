第一章Work

Selected work

Robots, vision, and a few things built for fun.

  1. 01VLM + RL · MuJoCo · Qwen3-VL · PPO

    VLM-Guided Legged Robot Navigation with Revisable Memory

    A frozen Qwen3-VL navigator steers a PPO locomotion policy (Go2/G1, MuJoCo). I designed a revisable belief memory for out-of-view target search that drops stale beliefs on contradiction, with memoryless and frame-history ablations.

    GitHub: VLM navigation ↗

  2. 02PPO · Gymnasium · FastAPI · WebSockets

    Poker RL: 6-Max No-Limit Hold’em Self-Play Agent

    A MaskablePPO self-play agent trained against a pool of frozen policy snapshots in RLCard 6-max No-Limit Hold’em, evaluated in mbb/hand with 95% CIs. It runs as a real-time browser poker table over FastAPI + WebSockets, with CI and tests.

    GitHub: Poker RL ↗

  3. 03YOLO11 · ByteTrack · Docker · Computer Vision

    FlowCount: Real-Time Traffic Analytics

    YOLO11 detections feed a ByteTrack-style tracker (Kalman filter + Hungarian matching) for line counts, wrong-way alerts, zone occupancy, and heatmaps from webcam, video, or RTSP input. Web dashboard, Docker deploy, CI.

    GitHub: FlowCount ↗

  1. 04

    RL in Isaac Lab

    My fork of Isaac Lab for robotic simulation and training: multi-agent systems and legged locomotion in physics-based environments, with LocoMuJoCo for imitation and benchmarking.

    GitHub: RL in Isaac Lab ↗

  2. 05

    Signal Denoising at Idaho National Laboratory

    The model behind the INL internship: a ResNet autoencoder that cleans noisy smart-grid sensor signals so anomalies stand out.

  3. 06

    Senior Project: Autoencoder State Compression for RL

    Compressing the observations a PPO agent sees with an autoencoder, and measuring how compression affects RL performance, for efficient deployment in resource-constrained environments.

    GitHub: senior project ↗

  4. 07

    Railway Crossing Accidents at UC Riverside

    The open-source code behind the ASME JRC 2024 paper: spectral clustering over USDOT railway crossing accident records.

    GitHub: railway crossing accidents ↗

  5. 08

    Personalized Chemotherapy Dosing

    A Decision Transformer learns personalized dosing from offline patient data, framing treatment planning as offline RL. Published at ICICT 2025.

    Paper: chemotherapy dosing ↗

  6. 09

    Neon Grid

    A walkable ASCII cyberpunk city in a single HTML file: a first-person raycaster with no engine, no libraries, no assets.

    Play Neon Grid ↗GitHub: Neon Grid ↗

  7. 10

    Chess-AlphaGO

    AlphaZero-style self-play for Gardner chess (5 × 5) built on Pgx, with batched, JIT-compiled GPU rollouts in JAX and MCTS via Gumbel MuZero.

    GitHub: Chess-AlphaGO ↗

第四章About

About

I’m Hector, a CS master’s student at UTRGV. I work on getting robots to move and to understand what they’re looking at: reinforcement learning for legged locomotion, computer vision, and vision-language models for navigation.

In summer 2026 I was an AI/ML research intern at the Air Force Research Laboratory, studying how vision-language models handle multi-camera video. The internship has ended, but I’m still working on that research, and a manuscript is in preparation. At UTRGV’s Machine Intelligence Lab I trained locomotion and navigation policies for the Unitree Go2.

When I’m not training agents, I train myself: taekwondo and hiking, slowly working up to summiting a real mountain.
